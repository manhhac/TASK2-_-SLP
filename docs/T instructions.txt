# Hướng dẫn tạo PDF từ báo cáo

## Cách 1: Dùng HTML (đã có sẵn - KHUYẾN NGHỊ)

1. Mở file `docs/TASK2_REPORT.html` trong browser (Chrome/Edge/Firefox)
2. Nhấn Ctrl+P (Print)
3. Chọn "Save as PDF" hoặc "Microsoft Print to PDF"
4. Lưu thành `TASK2_REPORT.pdf`

## Cách 2: Dùng Markdown Editor

1. Cài Typora (https://typora.io/) hoặc VS Code với Markdown Preview Enhanced
2. Mở `docs/TASK2_REPORT.md`
3. File → Export → PDF
4. Lưu thành `TASK2_REPORT.pdf`

## Cách 3: Dùng Google Docs

1. Vào https://docs.google.com
2. File → Open → Upload
3. Upload `docs/TASK2_REPORT.md`
4. File → Download → PDF Document (.pdf)

## Cách 4: Dùng Word

1. Mở Word
2. File → Open → Chọn `docs/TASK2_REPORT.md`
3. Word sẽ tự động render markdown
4. File → Save As → PDF

---

**Đã có sẵn:**
- `docs/TASK2_REPORT.html` - HTML formatted (cách 1)
- `docs/TASK2_REPORT.md` - Markdown gốc (cách 2, 3, 4)

**Khuyên dùng:** Cách 1 (HTML → Print to PDF) - nhanh nhất và đẹp nhất
